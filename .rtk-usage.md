# .rtk/ — Runtime Scratch Directory

`.rtk/` is a repo-local scratch space for runtime/temporary files an agent or dev script produces while working in this project. It is **not** related to the `rtk` (Rust Token Killer) CLI proxy some contributors may have installed globally — same name, unrelated tool. Nothing under `.rtk/` is committed (see `.rtk/.gitignore`).

## What goes in `.rtk/`

- Ad hoc debug dumps while investigating a bug (e.g. a captured IPC payload, a SQLite query result you're inspecting)
- Scratch build/log output from a one-off script run
- Temporary exports used to compare before/after state during a refactor

## What does NOT go in `.rtk/`

- Anything the app reads at runtime — real runtime data belongs in Electron's `app.getPath('userData')` (where `DatabaseService`, `FileStorageService`, and `MediaCacheService` already store the SQLite DB, media cache, and workspace config), not in the repo.
- Source code, tests, or anything meant to be reviewed/merged.
- Secrets or credentials — `.rtk/` is gitignored, not encrypted; use `src/services/secure/SecureSettingsService.ts` for anything sensitive.
- Generated docs or reports meant for the team — those belong in `docs/`.

## Note for this project specifically

Deplao's actual runtime state (DB, media cache, logs) already lives outside the repo in the OS `userData` directory by design (see [CLAUDE.md](CLAUDE.md) and [src/services/CLAUDE.md](src/services/CLAUDE.md)). `.rtk/` is only for throwaway artifacts produced *during development of this repo itself* — it has no role in the shipped app.
